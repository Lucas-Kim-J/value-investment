Product Vision · v2

不是一个网站，是一台
「学习驱动」的价值投资 OS

把网站从「只读的资料堆」变成一个闭环：你学的每一样东西都留痕、被验证、变成你分析持仓与公司的认知底座；hermes 的分析随你的成长而进化。

这份文档是产品理念的公开说明，也是 v2 改造的设计依据。由 4 个不同视角的 subagent 辩论后综合而成。

核心循环

整个产品只服务一个循环——它必须真的转起来，而不是停在任何一环：

学一手内容（letter / AGM / 13F / 季报 / 演讲 = 认知底座）
  ↓ 留痕 + 验证（不是"看了就算"，要能复述、能应用）
成就 / 进度（只认"可证伪的承诺"和"事后验证的判断"）
  ↓ 这些成为你的"学习画像"
分析持仓 / 公司（hermes 按你的画像给个性化审视，而非固定提示词）
  ↓ 归档 + 复盘
发现认知缺口 → 回到「学一手内容」补上

关键：一手内容是底座。letter / AGM / 13F / 季报 / 演讲是大师们的原始思维，是你认知的底层框架——优先学它，胜过学二手解读。

七条不可动摇的原则

这些是 4 个 subagent（学习科学 / 产品 UX / 技术架构 / 红队批判）辩论后共识的底线。它们防止产品退化成"看起来很全但没人真用"。

1
窄而真 > 宽而假。 宁可 3-4 个你天天用的功能，也不要 23 个半成品。上一版的失败正是"看起来很完整"。
2
真的学到，才算学到。 验证不是打勾——要能用自己的话复述（费曼）、能应用到你真实的持仓上。「看完」只给"在读"，通过验证才给"已掌握"。
3
成就只奖励"判断"，不奖励"动作"。 不做连续打卡 streak、不奖励"读了几本/分析了几家"。只认可证伪的 thesis、"我改变了主意"、把自己的错误归档——这些刷不出来。
4
个性化只改"详略"，不改"约束"。 hermes 的方法论约束永远固定（不荐股、数据不足就说不足）；只有"对新手多解释、对老手更犀利"这一层随画像变。
5
诚实地不完整。 一手内容不可能采全，也不该让 AI 去"代读"。我们只给官方链接 + 概念级导读 + 笔记位。覆盖度公开标注，缺口大方承认。
6
绝不编造。 AI 绝不生成具体数字、持仓、引文、"最新"陈述。涉及数字一律 → 官方原文链接。系统在不知道时大声说"我不知道，这是原文"。
7
你的数据神圣。 持仓存 PostgreSQL + 每日备份。只新增表、绝不删改你的数据。（已从一次误删事故中吸取教训。）

四个意图，而非二十三个文档

用户来这里只有四个意图。导航就按意图组织，而不是按文件分类：

意图去哪留什么痕
📖 我要学学习路径 + 方法论 + 一手内容库读了什么、复述、应用到持仓
🔍 我要查一个词术语 Wiki（全站 ⌘K 即点即查）查过 / 用自己话讲对了 = 掌握
💼 我要管我的仓持仓输入 + 规范报告持仓、thesis、决策、复盘
🏢 我要分析一家公司一键分析 + 归档对比每次分析存档，可回看演进

四大支柱（v2 新增）

① 一手内容库 Primary Sources

letter / AGM / 13F / 季报 / 演讲，按来源 + 人物组织。每条带覆盖度徽章： 导读官方链接 + 我们的概念级读法； 仅链接官方链接 + 一句为什么； 待补已知缺口，大方承认。 绝不含 AI 编造的数字或引文。

② 术语 Wiki（嵌入交互）

文章里的术语即点即查（hover 卡片）；全站 ⌘K 速查；用"自己的话"复述通过才算掌握。掌握的术语会成为 hermes 分析你持仓时的上下文。

③ 学习留痕 + 轻量成就（服务端）

学习状态从浏览器搬进数据库——换设备同步、可被验证、可个性化。成就只挂"可证伪的产出"，与真实能力提升绑定。

④ 公司一键分析 + 归档

从持仓或搜索框一键分析，hermes 按你的学习画像审视，结果归档到「我的公司库」，可回看同一公司不同时间的分析演进。

⛔ 我们刻意不做的事（红队定的红线）
  • 不让 AI "整理" 13F / 季报里的具体数字——必编，且自信，最危险。只给官方原文链接。
  • 不做连续打卡、排行榜、攀比——会把"诚实记录"反向激励成"刷数字"。
  • 不做向量库 RAG 问答——5-20 家公司直接读 10-K 更深。
  • 不做实时行情 / K 线 / 盘中推送——价值投资反盘中。
  • 不把"学得多"和"分析准"挂钩制造错觉——分析质量取决于基本面与方法论严谨度。

分阶段交付

v2 是渐进的。每个功能要么完整可日用，要么明确标"占位/半成品"，绝不把半成品当成品。

  • 基础 学习状态迁到 PostgreSQL（留痕的地基）
  • 基础 术语 Wiki + 全站即点即查
  • 基础 一手内容库（官方链接 + 概念导读 + 笔记位）
  • 基础 意图导航 + 新首页
  • 增量 公司一键分析 + 归档
  • 增量 轻量成就（证据驱动）
  • 演进 学习验证闸门（费曼复述 / 应用到持仓）、个性化详略档位、间隔重复
