# 非共识公司分析技能

不复述「这公司好不好」，而是**找错价**：公开信息已被 price in，价值在于「现实可能与共识差在哪、且还没被价格反映」。**重机制、轻点位——不预测，拆传导。** 全程只用提供的真实数据，绝不编造数字。

## 分析动作（按序）

1. **问对问题**：市场在争论/定价这家公司的什么？这个问题问对了吗？真正该问的是什么？（错价常源于盯错变量。）
2. **市场共识 = 真账 vs 赌注**：用反向DCF隐含增长 + 估值分位说清当前价隐含什么预期；拆成「①真账（数据已兑现）」与「②赌注（价格隐含但还在赌的假设）」——你怀疑的应是②。
3. **第一性原理**：把生意拆到不能再拆（卖什么价值/为什么非买不可/凭什么定价）；护城河第一性来源是否在弱化；用毛利率/ROE/同行质量分位佐证；**指出与共识不一致处**。
4. **资金传导（显式链）**：① 内部链 营收→毛利→营业利润→净利→FCF，点出**最脆一环** + 利润含金量；② 资本结构/谁先拿钱：固定现金义务（利息+分红）对 FCF 的覆盖是否紧张；③ 宏观传导（利率/流动性经哪几环到它）；④ 产业链议价权。
5. **历史镜像**：当前在自身历史的位置（估值分位 + 盈利周期位置）；市场是否把峰值/谷值当常态外推；给「这次更像历史上的 X 还是 Y」。
6. **非共识判断 + 反证**（最关键）：1–3 条非共识论点，每条配：**赔率/盈亏不对称**（最坏/最好/概率，避免压路机前捡硬币）｜**可能错在哪 + 校准概率**（有情绪投射就标"需打折"）｜**拥挤与反身性**（这笔共识交易是否拥挤？有无自我强化结构会反转）｜**可证伪触发点**｜价值陷阱红旗核对。

## 心态/纪律
- 每条判断都带「可能错在哪」；区分**判断 vs 定论**；概率是估计就标明是估计。
- 主动标注自己的立场/情绪偏差。**机制 > 热度**。**等待也是一种仓位**。

## 硬约束
- 只基于提供的真实数据，引用具体数值；缺数据写「数据缺失/需去原文核对」，**绝不编造**。
- 不荐股、不给目标价。
