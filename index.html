价值投资方法论 · v1.1

从清单到 SOP：
把方法论砍到难看但管用

为 lucas（在校 + 实习，约 10h/周可投入）设计的 B 轨方法论。覆盖美股、A股、加密三个市场（重心 US 50% / A-share 30% / 加密 20% 上限 5% 仓位）。v1.1 吸收了批判性 review 的 18 条修订，砍掉伪科学（前 180 天禁 DCF、不用 S2F、不用 30 分钟 daily 仪式），加上四个新章节（开始之前 / 失败案例 / 心理与卖出 / 税务外汇）。

v1.1 · 2026-06 · 上一版本：v1.0（同日早些时候）· 文件 value-investment/index.html

核心原则（v1.1 重申）： 真正级别的大佬绝大多数不靠 X 输出。一手内容是 letter / AGM / 13F / 季报 / 演讲。但更重要的是：把"经典文本"和"持续信号流"分开——前者一次性学完进入档案，后者订阅 + 定期消费。把考古和现役混在一起会让 routine 变成仪式表演。

0. 开始之前

未完成下面任一项的人，不应该开始这套方法论。价值投资在错误的财务前置条件下 = 灾难放大器。

  • 3 个月生活费的现金缓冲（货基 / 高息活期）。没有缓冲的人在熊市底部会被迫割肉——而熊市底部恰好是失业 / 实习中断的高发期。
  • 收入稳定预期（实习/工作 12 个月内不被打断的合理预期）。
反向检查：如果上面任何一条没勾掉，先解决这些再回来。这不是耽误，是基础建设。

1. 缘起 & 轨道选择

价值投资的本质：以低于价值的价格买入未来能持续创造价值的资产。但对一个时间有限的学习者，真正决定结果的不是"知道多少流派"，而是"持续做什么"。

轨道说明

轨道时间仓位 / 组合自动化定位
A 轨3-5h/周仓位 < 20% 净资产，主要 ETF + 少量精选偏监控
B 轨（你的）10h+ /周5-10 只个股 + 季度深度研究signals + 半自动下单
C 轨20+ h/周类专业全栈自建

你的 10h+ 大致分布：工作日 1-2h（早晨 15 min 扫读 + 晚 45-90 min 阅读） 周末 4-6h（深度研究 + 周复盘）。具体见 §15 Routine。

"Risk comes from not knowing what you're doing." — Warren Buffett

2. 选派：先精通 Pabrai + Marks（3 年）

七大流派看似互补，实则路线之争（Graham 烟蒂 vs Buffett 优质 / Munger "宁要伟大公司贵一点" vs Marks "价格决定一切" / Damodaran "万物可 DCF" vs Buffett "我从不算 DCF"）。新手并列学会风格漂移——这家按 Munger 买，那家按 Marks 嫌贵，没有任何一种被坚持到产生统计意义。

v1.1 决定起点：Pabrai + Marks。理由：资金少、时间少、防御性强、避错优先，最适合 B 轨学习者。

Pabrai 给你的实操骨架

  • Dhandho：Heads I win big, tails I don't lose much（低风险 + 高不确定性下的非对称下注）
  • 克隆大佬：Dataroma / 13F 跟踪 5 位 super-investor，但只用来产生 watchlist，不直接 clone
  • 凯利公式半数：单仓位上限 10%，集中后期可到 20%（B 轨建议先守 10%）
  • 少而精：60 年 20-30 个真正 bet 就够。研究上瘾是变相恐惧

Marks 给你的判断锚

  • 风险 = 永久性资本损失的概率，不是波动率
  • 市场周期是钟摆，永远在两端徘徊；现在处于钟摆哪一端？
  • 第二层思维：所有人都看好时，你看到了什么别人没看到？
  • Oaktree Memos（月度免费）是全球投资读物 ROI 第一

3 年后再吸收 Buffett（护城河 + 资本配置）、Damodaran（估值工具）、Munger（多元思维）。Graham 的烟蒂法在 2026 年的全球化 + 无形资产时代效用衰减，可不学。

3. 估值工具（前 180 天禁用 DCF）

v1.1 重要修订：新手前 180 天 不要 用 DCF。DCF 对增长率、折现率、永续率极度敏感，新手凭感觉填入三个猜想数字，得到看起来精确的猜想，然后带着虚假自信加仓。Buffett 本人公开说他不用 spreadsheet 算 DCF —— "如果你需要算到第三位小数才能判断便宜，那就不够便宜"。

前 180 天默认工具栈（够用且不假装精确）

工具用法解读
反向 DCF当前价格隐含的未来增长率是多少？对比 GDP / 行业增长 / 历史增长，判断隐含假设是否合理
历史 P/E 百分位当前 P/E 在过去 10 年的位置底部 25% 分位 = 值得看；顶部 25% = 需要 thesis 解释为何更贵
EV/EBIT 同行对比跨资本结构、跨折旧政策更公允同行最便宜 30% + 质量更好 = 候选
Owner Earnings Yield vs 10Y(净利+折旧-维持性 capex) / EV，对比 10 年美债收益率差额 > 4% 是合理 hurdle

替换"三档情景概率加权"为 Pabrai 检查清单

不要假装算概率，问三个具体问题：

  1. 最坏情况我亏多少？（具体到金额）
  2. 我能心理与财务上承受吗？（是 / 否）
  3. 如果对了，赔率至少 2:1 吗？（潜在涨幅 / 潜在亏损）

三个都是 yes 才下注。180 天后再引入 DCF + 情景分析。

4. 投资流程（7 阶段 + 卖出独立成章见 §8）

  1. 筛选：Finviz / TIKR / Stockanalysis（美股）、AKShare 自写脚本 / 理杏仁（A股）。初筛条件：ROIC > 15% × 5 年 + FCF 增长 > 10% + 净负债/EBITDA < 3。
  2. 行业理解：波特五力 + 产业链地图。关键问题：增长来源？集中度？谁定价？技术变革风险？
  3. 公司研究：Buffett 12 条改编（生意简单 / 历史经营 / 长期前景 / 管理层 / ROE / Owner Earnings / 利润率 / 留存价值 / 护城河 / 资本配置 / 内在价值 / 折扣）。
  4. 估值：见 §3，用 4 个默认工具。
  5. 仓位管理：凯利半数；单仓位 ≤ 10%（B 轨初期）；总仓位与现金管理参考 Marks 的"防御 / 进攻"切换。
  6. 持有与复盘：季度复盘原始 thesis 是否仍成立。季报必读：营收质量 / 应收账款 / 存货 / 经营现金流 vs 净利润。
  7. 卖出：独立成章，见 §8。

5. 市场适配差异

美股

信息透明（SEC EDGAR 全套 10-K / 10-Q / 8-K / DEF 14A）、估值合理、流动性好。价值投资框架原版套用。

A股

监管政策权重大、散户主导（情绪驱动）、估值波动剧烈。北向资金是"聪明钱"风向标。适配：放大安全边际、避高商誉/股权质押、谨慎"政策概念股"、关注分红+ROE 稳定的优质公司。一手公告看巨潮资讯网。

加密

见 §13——v1.1 已重定位为"非对称配置"而非价值投资延伸。

6. 价值陷阱识别

  • 低 P/E 但行业结构性衰退（柯达 / 燃油车整车 / 纸媒）
  • 高股息靠借债维持（payout > 100%，FCF 不足）
  • 资产被高估：账面是过时设备 / 不良应收 / 僵尸库存
  • 公司治理：大股东掏空 / 关联交易 / 频繁换审计
  • 周期顶部低 P/E：航运 / 煤炭 / 半导体周期顶 EPS 最高，下一年腰斩
  • 会计红旗：经营现金流 < 净利润 / 应收增速 > 营收增速 / 商誉 > 净资产 30%

快速排雷：Beneish M-Score（造假）、Altman Z-Score（破产）、Piotroski F-Score（质量）。

7. 失败案例研究 NEW

不读失败者的方法论永远是宣传册。下面六个 case 必须研究，每个写一份 500 字归因笔记：

案例核心教训
Bill Miller（Legg Mason，连续 15 年跑赢 S&P 后 2008 几乎归零）杠杆 + 价值陷阱（金融股 averaging down）+ 拒绝认错。"长期 outperformer" 的尾部风险
David Einhorn（近 10 年跑输市场）结构性看空 + 风格失衡 + 在成长股周期里坚持深度价值。这一条直接挑战"必追 Greenlight letters"的建议
Eddie Lampert（Sears）用价值投资框架做企业再造 ≠ 投资；CEO 跨界陷阱
王亚伟时代后的中国明星私募（徐翔 / 多位 2015 牛市顶峰明星）survivorship bias 教育：被神化时刚好是高点
LUNA / Terra（Do Kwon，2022 崩盘）"基本面看似良好"的庞氏 + 算法稳定币的迭代风险。价值投资框架在加密的失灵案例
FTX / SBF（2022 崩盘）"机构背书"和"治理透明"在加密里近乎为零

每个 case 笔记结构：① 当时多数人为何看好 ② 关键事实何时该警觉 ③ 如果我当时持仓，决策点在哪里 ④ 这个教训如何修改我的清单。

8. 心理与卖出 NEW

4 个必须建立的心理模型

  • 损失厌恶：亏损的痛 >> 收益的喜（2.5×）。会让你过早卖盈利 + 过晚卖亏损。
  • 锚定：你买入价不是市场关心的，但你的大脑会拿它做参考点。
  • 处置效应：倾向"卖盈持亏"，结果组合越来越烂。
  • FOMO：错过 NVDA / BTC 的痛会推你在下一个泡沫顶接盘。

50% 回撤心理预演

动手算：如果你的组合现在打 5 折（50% 回撤），账户金额是多少？想象那个数字 6 个月。这不是想象，是必须做的练习。价值投资者的常态成本是 30-60% 回撤（Buffett 在 1973-74 / 1999-2000 / 2008 各经历一次）。没做过这个预演的人，第一次真实回撤会割在底部。

卖出决策树

thesis 还成立吗？
├─ 否 → 立即清仓（不管赚亏）
└─ 是 → 估值还合理吗？
       ├─ 严重高估（>fair value 50%）→ 部分减仓（保留核心仓位）
       ├─ 合理 → 持有
       └─ 出现明显更好的机会 → 换仓（计算税务成本）

每季度一次：仓位偏离目标配置 > 20% → 再平衡

9. 税务 / 外汇 / 政策风险 NEW

税务（中国居民视角）

  • 美股：填 W-8BEN（中美税收协定）→ 股息预扣 10%；资本利得在中国居民身份下美国不征，回到中国境内合规申报。
  • A股：印花税单边 0.05%；个人股票交易免所得税；分红按持有期分级（< 1 月 20%、1 月 - 1 年 10%、> 1 年 免）。
  • 加密：中国居民税务定性模糊（"非法币"）；如果未来作为美国 resident 则每笔交易都是 taxable event（LIFO / FIFO 选择影响巨大）。

外汇（USD / CNY）

  • 2016: 6.6 → 6.95；2018: 6.3 → 6.9；2020: 7.1 → 6.4；2022: 6.3 → 7.3——美元仓位的盘面收益和人民币回算收益可以差 15%+。
  • 小资金不建议 hedge（成本吃掉 alpha）。要做的是心理准备：账户人民币计价波动会经常和盘面"看起来"严重背离。
  • 每月 1 次记录"以 USD 计价 vs 以 CNY 计价"两条收益曲线，避免单一视角误导决策。

政策与监管

  • A股：双减 / 反垄断 / 消费税传闻可以一夜让 DCF 归零（2021 教培、2021 互联网、2024 白酒预期）。任何 DCF 都要折扣"政策风险"。
  • 中概股：VIE 结构 + ADR 退市可能（2022 一度恐慌）。仓位单独限额。
  • 加密：SEC 对 ETH 的定性 / 中国全面禁止存量 / EU MiCA 二期 / 美国稳定币立法。仓位上限 5% 净资产是政策风险的天然 hedge。

13. 加密：非对称配置（非价值投资延伸）

v1.1 重定位：加密不是价值投资框架的延伸。BTC/ETH 没有现金流，估值锚不稳。S2F 模型已被实际数据证伪（2021 预测 BTC $100K 实际 $46K；2024 预测 $150K+ 实际 60-70K 震荡）。把加密塞进 DCF 是糖衣的赌博。

正确定位：非对称下注

  • 仓位上限：5% 净资产（凯利公式视角，不是估值视角）
  • 配置逻辑：BTC = 长期持有抗通胀实验；ETH = 网络费收入跟踪 + 生态实验；DeFi 协议 = 用 P/S 但仓位极小
  • 不用：S2F、"四年减半周期"线性外推、"机构必将采纳" narrative
  • 用：链上指标作风险提示（exchange net flow、稳定币增发、ETF 资金流）

数据 / 链上工具

  • Token Terminal — 协议收入数据
  • DefiLlama — DeFi TVL
  • Glassnode 免费层 — 链上指标
  • Messari — 协议研究
  • Dune — 自定义链上 query

14. 播客（v1.1 砍 70%）

  3. ⭐ In Good Company（Nicolai Tangen，NBIM CIO）— 精选 1-2 集 / 月。最高密度 CEO/投资人访谈。

15. Routine 节奏（B 轨 ~10h+ /周）REDESIGNED

取消 v1.0 的 30 分钟 daily 仪式。北京时间 07:30 美股已收盘 3.5h、A股未开、加密只是过夜数据——三个市场信号最稀薄的时刻。价值投资本来就不需要实时。

工作日早晨 · 15 min × 5

时间动作
5 min雪球 App / 东方财富看 A 股集合竞价 + 北向资金（仅 09:15-09:30 时段）
5 min看自动推送的美股隔夜收盘 + 持仓异动（飞书推送，见 §17）
5 minJournal 三句话：昨日动作 / 今日 thesis 是否变化 / 风险点

工作日晚 · 45-90 min × 5

  • 当前正在研究的公司：下一节 10-K / 一段季报（30-60 min）
  • 一篇 Oaktree memo / 一封 Pershing letter / 经典文本一章（15-30 min）
  • 财报周可加：当周持仓公司财报扫读（30 min）

周末

  • 周六 3-4h：公司深度研究 chunk（竞品对比 / 行业地图 / 估值刷新）+ 写 thesis 一段
  • 周日 1.5-2h：周复盘（journal 串起来 / 归因 / watchlist 调整 / 下周计划）

每月 1 次（4h，月末周日替代周复盘）

  • 月度归因：跑赢/跑输的原因，归因到"运气 vs 能力"
  • 行为日志统计：情绪驱动 vs thesis 驱动决策的占比
  • 读 1 个失败案例（§7 名单），写 500 字归因笔记

每季 1 次（8h，季末周末）

  • 持仓重审：每个仓位重新论证 thesis
  • 季度 letters 阅读：Pershing / GMO / 中国基金经理季报 / Damodaran 季度 update
  • 13F diff（Dataroma），更新 watchlist

总计：早 1.25h + 晚 5h + 周末 5h ≈ 11h/周 + 月度 4h × 1/4 ≈ 1h/周 摊销 + 季度 8h × 1/13 ≈ 0.6h/周 摊销 ≈ ~12.5h/周。符合 B 轨设计。

16. 工具栈（基于开源调研）NEW

数据层（B 轨"装好就够用"组合）

18. 学习路径 90/270/720REWRITTEN

真实退出率提醒：类似自学课程的完成率，30 天约 50%，90 天 10-15%，180 天 < 5%。读到第 30 天会想放弃，这是正常的。本方法论假设你已经决定加入剩下的 10%。

Day 1-90：跑通第一家公司 + Pabrai/Marks 入门

  • 选 1 家日常使用的美股公司（Costco / Hermès / Apple / Visa）
  • 读 5 年 10-K（每周 1 年）
  • 同步读 Marks《The Most Important Thing》+ Pabrai《Dhandho》
  • 简版估值：反向 DCF + EV/EBIT 历史百分位 + Pabrai 检查清单
  • 写 1500 字 thesis + 决策日志 + 退出条件
  • 开 paper trading 账号
  • 产出：第一份完整 thesis + Pabrai/Marks 笔记

Day 91-270：第二、三家公司 + 系统化

  • 每 6-8 周一家公司（节奏可下调，新手第二家通常仍很慢）
  • 第二家：A 股优质公司（建议消费 / 医药白马，先学习国内市场结构）
  • 第三家：港股或新兴市场
  • 启动 paper trading 实际下单
  • 启动半自动化：M1 飞书早报
  • 月度归因 + 读 1 个失败案例 / 月
  • 读完 Oaktree memos 精选 30 篇 + Buffett Partnership Letters
  • 产出：3 份 thesis + 自动化早报 v1 + 12 个月 paper trading 记录

Day 271-720：实战与体系化

  • 真实小额资金（< 流动资产 20% 净资产）执行 5-10 只组合
  • 经历 1-2 次回撤（如有，写心理日志归档）
  • 季度持仓重审 + 月度归因 + 失败案例 12 个
  • 读完剩余经典文本（Munger / Marks 周期 / Nomad / Klarman / 段永平历史）
  • 180 天后可引入 DCF（结合 Damodaran 工具书）
  • Day 720 写 "我的投资体系 v2.0"（3000 字+），含买入清单 / 卖出清单 / 仓位规则 / 复盘模板
  • 产出：完整可执行的投资 SOP + 真实回报曲线 + 1 份失败复盘
