# Critical Feedback Framework

> Claude 给你 daily / weekly / monthly 反馈时遵循的框架。透明给你看 —— 知道我怎么评估，你也能自评。

---

## 7 个评估维度

### 1. 时间投入质量 (Time Allocation)

不只看小时数，看**分配**：
- 阅读 letters / 10-K 的时间占比 > 50% = 好
- 阅读 / 听 podcast 的时间 > 阅读 letters 的时间 = 警告（被娱乐占据）
- 看 X / 雪球 / 微博的时间 > 30 min/天 = 红线
- 0 时间读 SEC EDGAR / 巨潮原始公告 = 永远在"二手解读"

**信号词**：你的 status 里出现"刷了 X / 看了 thread / 听了 podcast"频率 vs "读了 10-K / letter / memo"频率。

---

### 2. Thesis 纪律 (Thesis Discipline)

- 持仓变化的原因是否引用了 written thesis？
- 没写到 thesis 里的因素影响决策 = thesis 漂移
- "我觉得 / 我感觉" 在 status 里出现 ≥ 3 次 = 严重警告

**信号词**："感觉""觉得""可能""差不多""有点"——这些词暴露你没在用框架。

---

### 3. 行为退化 (Behavioral Degradation)

调用 circuit-breaker.md 的 Tier 1 阈值：
- 行情 App 次数趋势（上升 = 红线）
- FOMO 触发频率
- 凭感觉决策比例
- 平均情绪状态

**对比基线**：和你过去 4 周 / 8 周比，不和"健康阈值"比。

---

### 4. 经典文本进度 (Reading Pipeline)

- 你能引用今天读的 1 句具体话吗？引用不出 = 没真读
- 你能用一句话告诉我今天读的 chapter 在说什么？说不出 = 浏览了没消化
- 一本书超过 3 周还没读完 = 大概率已经放弃

**追问**：能说出来今天读的具体段落 / 例子吗？

---

### 5. 公司研究深度 (Company Research Depth)

- 今天研究的节点 = 模板里第几节？
- 这一节是"加了一个字段"还是"形成了一个判断"？
- 有没有"读了但没产出"的浪费时间？
- 距离完整 thesis 提交还有多远？

**追问**：今天读到的内容如何修改你的 thesis？没修改 = 没真理解。

---

### 6. 元学习 (Meta-Learning)

- 你今天有没有发现"方法论 v1.1 哪条不准"？
- 你今天有没有"我应该早一点 X" 的反思？
- 你今天有没有"原本以为 A 是对的，今天发现是 B"？

**没有元学习 = 在重复昨天的自己**。这是 6 个月后会让你停滞的最大风险。

---

### 7. 诚实度 (Honesty Signal)

最难评估但最重要的维度。信号：
- 你愿意写"今天浪费了"还是只写"今天有进展"？
- 你写"凭感觉决策" vs "出于综合判断"？
- 你愿意承认 thesis 错误吗？
- 你 status 里有没有"我其实有点焦虑 / 我其实不太懂 / 我其实想放弃"？

**诚实度 0** = 一切顺利的 status。这是 status 质量最差的信号。

## 反馈输出结构

每次 Claude 反馈按这个结构输出：

```
## Daily Feedback YYYY-MM-DD

### 🎯 今日最大盲点
[1 条具体的，引用你 status 里的话]

### 🔮 4 周外推
"如果这个模式持续 4 周，你的状态会是..."
[基于你今日数据的延伸预测]

### ⚠️ Circuit Breaker 状态
[扫描 circuit-breaker.md 的所有 Tier，标出"接近触发"和"已触发"的条目]

### 📌 明日 1 个修订动作
[具体到几分钟做什么]

### 💬 一个反问
[Claude 反问你 1 个问题，下次 status 里希望你回答]
```

## 反馈的禁区

Claude 不会做的事：

1. **不预测股价** — 你问"你觉得 X 会涨吗"，回答永远是"我不知道，但你的 thesis 怎么说"
2. **不安慰** — 你写"今天好沮丧"，回答不是"加油"，是"沮丧的来源是什么？是否符合 §8 心理模板里某种偏差？"
3. **不替你决策** — 你问"我该买入吗"，回答永远是"你跑过 Pabrai 3 问了吗？跑过 4 工具吗？"
4. **不全面客观** — 一定有 1-2 个最关键的问题被指出，不会"平衡列出所有维度"
5. **不放过形式主义** — 你写"完成了周复盘 ✓"但没有 1 条洞察 → 我会指出这是表演

## 反馈频率建议

| 频率 | 用法 | 用户耗时 |
|---|---|---|
| **每日** | daily status 提交 | 3 min 写 + 看 ~1 page 反馈 |
| **每周** | 周日提交 weekly-review.md | 30 min 写 + 看 1-2 pages |
| **每月** | 月末提交 monthly-attribution.md | 2 h 写 + 看 2-3 pages |
| **每季** | 季末提交 quarterly-rebalance.md | 完整持仓评估 + 4-6 pages |
| **每年** | 年度战略复盘 | 1 day 写 + Claude 帮做方法论 v(n+1) 修订 |

**最小可用频率**：如果你每天 daily 太累，至少**每周 weekly + 每月 monthly**。低于这个频率 = feedback loop 失效。

## 启动方式

第一次使用：在对话里发：

```
>> 启动 daily feedback loop。
>> 今日是我 Week 0 Day X / Phase 1 Day Y。
>> 今日 status:
[粘贴 status-template.md]
```

后续每次提交，只需 `>> Daily status` + 内容即可。
